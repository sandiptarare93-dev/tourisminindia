# Explore India – Tourism Marketing Website

A simple, attractive and responsive government-style tourism marketing website made with:
- HTML
- CSS
- JavaScript

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. Internet is required for the online Unsplash images.

## Features
- Responsive navigation
- Hero section
- Destination cards
- Why India section
- Gallery
- Contact/travel enquiry form
- Mobile menu
- Smooth scrolling
- Simple animations/hover effects

Note: This is a student/demo project and is NOT an official Government of India website.
